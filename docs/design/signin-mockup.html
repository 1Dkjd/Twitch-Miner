Design notes
  • Order is fixed: the page password first, then Twitch, so nobody else on the network can reach the Twitch step.
  • Sign-in happens on Twitch's real page, shown live. This mockup draws a placeholder there and copies none of Twitch's look.
  • The paste box is there because a password manager can't fill a streamed browser. It sends text to that browser's clipboard, and you press Ctrl+V inside. It's unproven until phase 5 (Docker), so treat it as a proposal.
  • Until Docker (phases 3–4) the browser opens as a window on the PC running Drops Miner. That is the "on the PC" state.
  • Copy only promises what the code does. Only the Twitch token is saved; the page password is stored as a hash, and Twitch never sees it.
  • On a phone, tapping a streamed browser doesn't open the keyboard, so phones get a "Show keyboard" button (resize to phone width to see it). Unproven until phase 5.
  • Primary buttons use the approved strong style; amber stays reserved for progress and "what's next", as on Overview.
  • Open decision: recovering a forgotten page password. Nothing exists for it yet (the likely route is a command that clears it).
