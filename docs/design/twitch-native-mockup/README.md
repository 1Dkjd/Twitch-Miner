# Twitch-native mockup (approved 2026-10-31)

The approved visual spec for the web UI, replacing `../approved-mockup-v7.html`.
Original: https://claude.ai/artifact/2h7rk5hkBjRS2G71Y1YR9f

- `overview.html`, `priorities.html`, `inventory.html`, `history.html`, `phone.html`: each board rendered to plain
  HTML (open them directly; interactive bits such as Inventory's filters are frozen).
- `source/`: the boards as authored, with the canvas index. They need the design tool's runtime to render.

The numbers and names in them are sample data. Activity and Settings have no board; they follow the same style.
